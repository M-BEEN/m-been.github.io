모든 글이 사실과 다르거나 무가치하다는 판정은 아닙니다. 전체 외부 사실 검증도 완료하지 않았습니다.

`manifest.json`에 종전 URL, 원래 경로, 보관 경로, 원본 바이트 수와 SHA-256을 기록합니다.

공개 종료 81편에 포함하지 않습니다. 글별 처리 사유·남은 보강 항목은 `editorial-review-2026-10-02.json`에 있습니다.

이 폴더는 Hugo의 content/static 밖에 있어 페이지·RSS·사이트맵을 생성하지 않습니다.
Git 저장소는 공개이므로 비밀 보관소는 아닙니다. 과거 문서의 주장·제도 수치·전망을 현재 사실로 사용하지 마세요.
수정된 검산 글의 판정 데이터는 static/research/report-verdicts에서 별도로 재현할 수 있습니다.
